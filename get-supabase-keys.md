# Настройка Supabase ключей

## ✅ Ключи уже добавлены в .env.local

Если ключи не работают (ошибки в консоли), получите новые:

### Как получить новые ключи:

1. Откройте: https://supabase.com/dashboard/project/ytevoelicxcecwpetcqj/settings/api
2. В разделе **"Project API keys"** найдите:
   - **anon public** key (первая строка)
   - **service_role** key (нажмите "Reveal" чтобы показать)
3. Скопируйте новые ключи и замените в `.env.local`

### Если видите вкладку "Legacy keys" (устаревшие):

- Эти ключи могут не работать с новыми версиями Supabase
- Используйте ключи из основной вкладки "Project API keys"

### После обновления ключей:

1. Сохраните файл `.env.local`
2. Перезапустите dev-сервер: `npm run dev`
3. Проверьте консоль браузера на ошибки
